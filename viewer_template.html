Limitations & provenance

    Privacy: This viewer renders the embedded LUT data locally in your browser. It does not upload data, send telemetry, or load external assets. If you open the hosted page or click downloads, ordinary web requests to serve those files apply; the offline package works without any network.

    No apply/edit control: This tool only reads and visualizes the embedded LUT data. It cannot write, flash, or otherwise change the original factory source.
